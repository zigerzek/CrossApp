# CrossApp

Наскрізний проєкт з крос-платформного програмування.

Предметна область: Warehouse. Сутності: Goods, Batches, Balances, Transfers. 
Призначення: облік залишків товарів по партіях.

## Запуск застосунку
Для збірки та запуску проєкту використовуйте наступні команди[cite: 3]:

```bash
dotnet build
dotnet run --project src/Cli

Для виведення результату у форматі JSON (додаткове завдання) додайте відповідний прапорець:
dotnet run --project src/Cli -- --json

Середовище розробки
.NET SDK 10.0, Windows 10 x64[cite: 3].
